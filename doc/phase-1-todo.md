## 首版目标

从配置的 QQ 源群自动发现内容，构建带编号的原子观察快照，使用候选 worker 从上下文中选择零份或多份完整内容，每个窗口执行一次选材，再按额度以单条图文、逐条聊天合并转发及完整合并转发卡片广播到全部目标群并排除来源群，并从明确反馈更新群偏好。

首版不包含网页主动搜罗、个人画像或远程管理 HTTP API。接口支持后续来源和 agent 适配扩展。

操作员模拟转发提供本机认证 HTTP 入口，指定 QQ 字段与纯文本，保留明确模拟说明及独立回读验证。
